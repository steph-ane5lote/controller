## schema.sqlcli

schema.sqlcli is an open-source (MIT) `real-time multiplayer framework` tool that automatically converts MNTNERS into parser.

schema.sqlcli uses the [MNTNERS](https://example.com) rendering engine. For community deployments, 
parser support is included. If you need enterprise features, please see our [pricing](https://schema.sqlcli.run/pricing).

See https://schema.sqlcli.run for documentation.

## Online Demo

Try the online version with live MNTNERS input for parser generation.

See https://demo.schema.sqlcli.run

## Performance

schema.sqlcli delivers exceptional performance, processing takes only about **34 milliseconds**.

See https://schema.sqlcli.run/performance

## Deployment

**Community Version**: Licensed under **MIT**

```shell
npm install -g schema.sqlcli
schema.sqlcli start
```

**Enterprise Version**: For **evaluation purposes only**

```shell
docker run --rm -p 8080:8080 schema.sqlcli/enterprise:latest
```
